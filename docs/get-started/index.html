Get started

Ironmon adds a randomized challenge to Pokémon Infinite Fusion 2: Hoenn. Play with one Pokémon at a time, share seeds with friends, and use the tracker to see live battle information and review past runs.

The current alpha challenge ends when you defeat Wattson.

Ironmon is an independent fan-made add-on. The Pokémon Infinite Fusion team develops the base game separately.

Ironmon includes AI-generated code and artwork. This disclosure applies only to the Ironmon add-on.

Install with Setup

Setup gets a compatible Hoenn build and installs the Ironmon add-on. It can also update an existing installation.

Get Setup on GitHub Windows x64

Installation guide

  1. 1

    Run Setup

    Open the downloaded installer. Setup gets the compatible Hoenn game and selects the latest stable Ironmon release by default.

  2. 2

    Choose a folder and install

    Pick a folder. Review the versions and final location, then select Install. Fresh installs include the .NET runtime by default.

  3. 3

    Open the tracker and play

    Open Ironmon Tracker.exe to start the game. At the game’s title screen or main menu, select Play in the tracker.

    Keep the tracker connected. If it disconnects, your run pauses until it reconnects.

Other install options

Update an existing installation

v0.10.1 or earlier
When upgrading to a newer release, back up your saves and run the current Setup once. Point it at your existing game folder.
v0.10.2 or later
In the tracker, open Settings → Check for updates. If an update is available, read the release notes and select Update to review the installation.

Finish your active run before installing an update that changes the game version.

Install into an existing Hoenn game

Look in the top-right corner of the game’s title screen.

View matching ZIPs Go to Setup
  1. Choose Runtime included if you’re unsure. Choose Runtime required if the listed Windows x64 .NET Runtime is already installed.
  2. Back up your saves and close the game and tracker. Extract the full ZIP beside InfiniteFusion2.exe, merge the Data folder, then open Ironmon Tracker.exe.

Install a prerelease with Setup

  1. Open the current Setup and choose a separate folder to keep your stable game available.
  2. Expand Advanced: Ironmon version, choose a version labeled Test release, then review and install.

Experimental build. Test releases can change and may have regressions. To get a refreshed build with the same release number, download Setup again and select that version.

If Windows shows a warning

Microsoft Defender SmartScreen may show Windows protected your PC when it doesn’t recognize a download. If available, use More info to see the app details.

Check that you got Ironmon-Setup-win-x64.exe using Download Setup above. Stop if Windows reports a threat or if you’re unsure where the file came from.
