# Step 3.4 Part 4 validation

## Review boundary

This part generates deterministic complete-fusion destinations on demand and
routes standard two-component fusion evolution through them. Tracker target
lists and protocol work remain reserved for Part 5.

## Target pools and generation

The automated suite ran after normal game-data initialization inside Pokemon
Infinite Fusion 2's bundled Ruby runtime with seed `123456`.

- [x] The validated custom-sprite catalogue contained 174,348 ordered fusion
  identities.
- [x] Stage indexing retained 22,934 continuing targets and 59,046 terminal
  targets after excluding targets containing first-stage components.
- [x] Targets were indexed from their ordered body/head identities without
  constructing 174,348 dynamic fused-species records.
- [x] Every tested destination belonged to the validated custom-sprite pool,
  was strictly stronger than its displayed source, and contained neither
  source component family.
- [x] First-stage component branches selected continuing or terminal targets;
  intermediate component branches selected terminal targets only.
- [x] Body and head branches remained independent, including reversed source
  orientations and identical-component sources.
- [x] Each displayed source received different exact targets across all of its
  conceptual branches.
- [x] A 22-source matrix covered custom-sprite and autogenerated displayed
  sources, both component orientations, identical components, and 27 generated
  branches. The validation seed needed no closest-BST fallback in that matrix.

## Determinism, metadata, and cache behavior

- [x] Fusion generator schema and rules versions plus custom-target pool schema,
  size, and fingerprint were recorded in run metadata.
- [x] A changed fusion target-pool fingerprint was rejected explicitly as an
  incompatible `fusion target-pool catalog`.
- [x] Clearing the on-demand mapping cache reconstructed the same source branch

- [x] Seed `654321` produced a different mapping for the same displayed source.
- [x] Repeated lookup of a generated displayed source measured approximately

  queried, so Part 4 adds no work to the F7 reset itself.
- [x] The initial structural index measured approximately 577 ms in the final
  validation run.
