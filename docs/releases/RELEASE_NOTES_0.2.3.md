# Ironmon 0.2.3

This final Milestone 2 patch corrects starter acquisition.

- The selected starter is automatically accepted exactly as generated.
- Fused starters no longer offer Take, Reverse, or Unfuse choices.
- The rule applies to both the temporary rescue-battle addition and Birch's
  permanent lab addition, eliminating the duplicate pivot prompt.
- A fused starter receives no caught-fusion transformation right.
- Custom-starter selection follows the same rule.

The release retains the progression support from 0.2.2, the deterministic
fusion-reversal corrections from 0.2.1, and targets Pokemon Infinite Fusion 2
version 6.8.0.
