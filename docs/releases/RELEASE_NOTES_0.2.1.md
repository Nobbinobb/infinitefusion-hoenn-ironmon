# Ironmon 0.2.1

This patch release corrects the Milestone 2 fusion-reversal model.

- Opposite input orientations now receive two distinct, deterministic custom
  fusion results: `A+B=C` and `B+A=D`.
- Ironmon reversal swaps the result pair in both directions: `C↔D`.
- Reverse partners cannot share a component species.
- Custom fusion candidates require a selectable `main` or `temp` sprite;
  alternate-only entries that fall back to Japeal autogenerated art are
  excluded.
- Reverse-pair preparation occurs during run creation or save loading, avoiding
  a long pause on the first reversal.
- Existing eligible mappings preserve their first result and migrate to the new
  pair format. Stored results that are no longer eligible are rerolled.

The release targets Pokemon Infinite Fusion 2 version 6.8.0.
