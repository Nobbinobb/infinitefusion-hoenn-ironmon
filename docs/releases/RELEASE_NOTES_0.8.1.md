# Ironmon 0.8.1

Ironmon 0.8.1 unifies sprite presentation throughout the tracker, supports the
sprite data produced by both manual installation and Infinite Fusion's normal
download path, and adds an optional custom-sprite-library installer.

## Shared sprite presentation

- Use one size-configurable sprite component across the live Player and Enemy
  views, starter selection, active and archived Lookup, diagnostic views, area
  entries, evolution relations and candidates, and generated graph nodes.
- Open any available sprite in a larger accessible dialog with backdrop,
  close-button, and Escape-key dismissal.
- Render the enlarged dialog once at the application layout level so it stays
  above generated graph nodes and does not participate in node hover changes.

## Local and downloaded sprite support

- Resolve exact individually installed custom sprites before consulting local
  sprite sheets.
- Materialize tracker images from the sheets maintained by Infinite Fusion's
  normal download path, allowing a reinstalled game to populate sprites
  without requiring a manually copied spritepack.
- Preserve custom-to-autogenerated fallback behavior when a requested custom
  image is not locally available.
- Cache resolved tracker sprite paths by exact identity and variant.

## Optional custom sprite library

- Add **Settings > Custom sprite library** to prepare missing official custom
  fusion sheets before they are needed by tracker views.
- Download only missing sheets with four concurrent transfers, bounded retry
  and backoff, cancellation, basic PNG validation, and atomic temporary-file
  promotion.
- Resume naturally by skipping completed sheets after cancellation or an
  interrupted tracker session.
- Require Infinite Fusion to remain fully closed. Starting the game during the
  operation cancels active requests, removes partial files, and prevents them
  from being installed.
- Leave Infinite Fusion's **Download data** setting and normal download
  allowance unchanged.

## Installation guidance

- Explain that a new or reinstalled game can load graph and other sprite-heavy
  views more slowly while the game's local cache fills.
- Note that a first view can temporarily omit or fall back for some sprites
  when the game's normal local download allowance has been reached.
- Offer the tracker-owned custom-library installer as an optional preparation
  step instead of changing the game's default download policy.

## Compatibility

Ironmon 0.8.1 targets Pokemon Infinite Fusion 2 version 6.8.2. Existing 0.8.0
saves, seeded-run tokens, completed-run recipes, and tracker persistence remain
compatible when their recorded generator metadata matches the installed game
data. Install the game scripts and tracker from the same 0.8.1 archive.
