# Ironmon 0.7.7

This distribution targets Pokemon Infinite Fusion 2 version 6.8.0.

Copy the included `Data` directory into the game directory and merge it with
the existing `Data` directory. Only Ruby files are installed beneath
`Data/Scripts/997_Ironmon`.

Version 0.7.7 includes the cumulative Ironmon mechanics and tracker. Seeded
runs can be exported from an active or archived attempt, copied or saved as an
`.ironmon-seed` file, and transactionally imported on a compatible
installation. Battle-item control, aggregate type coverage, and signed,
optionally expiring diagnostic access remain available. The player package
contains no maintainer generator, release-data generator, audit, or private
signing-key material.

See the included `INSTALLATION.md` for complete installation, compatibility,
diagnostics, and removal instructions.
