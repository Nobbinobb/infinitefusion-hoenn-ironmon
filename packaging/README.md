# Ironmon 0.7.8

This distribution targets Pokemon Infinite Fusion 2 version 6.8.0.

Copy the included `Data` directory into the game directory and merge it with
the existing `Data` directory. Only Ruby files are installed beneath
`Data/Scripts/997_Ironmon`.

Version 0.7.8 includes the cumulative Ironmon mechanics and a refreshed fixed-
size tracker with compact navigation, aligned move information, tabbed Archive
content, paged area lists, per-save-slot history, and collapsible settings and
diagnostics. Seeded-run sharing, battle-item control, aggregate type coverage,
and signed, optionally expiring diagnostic access remain available. The player
package contains no maintainer generator, release-data generator, audit, or
private signing-key material.

See the included `INSTALLATION.md` for complete installation, compatibility,
diagnostics, and removal instructions.
