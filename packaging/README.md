# Ironmon 0.7.6

This distribution targets Pokemon Infinite Fusion 2 version 6.8.0.

Copy the included `Data` directory into the game directory and merge it with
the existing `Data` directory. Only Ruby files are installed beneath
`Data/Scripts/997_Ironmon`.

Version 0.7.6 includes the cumulative Ironmon mechanics and tracker. The Player
view's healing summary opens a five-category battle-item inventory, and carried
items can be selected there through the game's normal battle action flow.
Aggregate type coverage and signed, optionally expiring diagnostic access
remain available. The player package contains no maintainer generator,
release-data generator, audit, or private signing-key material.

See the included `INSTALLATION.md` for complete installation, compatibility,
diagnostics, and removal instructions.
